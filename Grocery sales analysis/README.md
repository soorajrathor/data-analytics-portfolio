Grocery Sales Analysis Dashboard – Power BI

Project Overview

This project is a Grocery Sales Analysis Dashboard created using Microsoft Power BI. It provides insights into grocery sales performance, product sales, payment methods, and profitability.

Key Performance Indicators

- Total Sales
- Total Quantity
- Total Profit
- Profit Percentage

Dashboard Analysis

- Monthly Sales and Profit
- Sales by Payment Mode
- Sales by Product
- Daily Sales
- Sales by Type
- Sales by Category

Tools Used

- Microsoft Power BI

Learning Source

This is a learning project developed by following a Power BI tutorial. It helped me understand dashboard development and sales data visualization.

Future Improvements

- Data cleaning using Power Query
- Creating and improving DAX measures
- Developing independent business insights
